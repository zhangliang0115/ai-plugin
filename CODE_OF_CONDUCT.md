# Code of Conduct

## Our standard

Be constructive and respectful. We're building shared infrastructure for a
global, multilingual community — English and Chinese are both first-class
languages here.

Examples of behavior that creates a welcoming environment:

- Gracefully accepting constructive criticism
- Focusing on what is best for the community and the users
- Showing empathy toward less experienced contributors

Examples of unacceptable behavior:

- Trolling, insulting or derogatory comments, personal or political attacks
- Publishing others' private information without explicit permission
- Spam, self-promotion unrelated to the project, or fake engagement
  (star farming, botting) — this project grows only through usefulness

## Enforcement

Maintainers may remove, edit, or reject contributions that violate this Code
of Conduct. Report issues to the maintainer via GitHub (issue or the contact
on the profile page). All complaints are reviewed and handled with discretion.
